# Plugin projects

No plugins have been added yet.

Each future plugin should live in its own directory and include:

- Source code and reproducible build instructions.
- An explicit license and any third-party notices.
- A README explaining its purpose and supported Desigma versions.
- A permission declaration covering network, storage, and document access.
- Tests and a small example design where useful.

Wait for a documented Desigma runtime contract before publishing an installable package. Do not copy packages from another platform without appropriate permission.
