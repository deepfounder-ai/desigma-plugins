# Plugin projects

[Installation demo](install-demo/README.md) tests native package installation without executing JavaScript.

Each future plugin should live in its own directory and include:

- Source code and reproducible build instructions.
- An explicit license and any third-party notices.
- A README explaining its purpose and supported Desigma versions.
- A permission declaration covering network, storage, and document access.
- Tests and a small example design where useful.

The initial installer supports the manifest described in the installation demo. Wait for a documented runtime contract before claiming a package can run. Do not copy packages from another platform without appropriate permission.


[Icon Browser](icon-browser/README.md) provides a working independent icon search and SVG export preview. Native installation and insertion are pending.
